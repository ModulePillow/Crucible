# 熔炉（二代）
简介：基于 DX12 从底层开发的小型渲染器，用于展示/研究图形渲染流程。是 PillowBasics 游戏引擎的前身。
- 实时 Mipmaps
- 实时 Shader 编译
- 前向渲染

开发背景：作者在前公司制定的年度学习计划（受主程监督进度）。

项目现状：**已废弃**。2025年起，作者转向开发强大的开源游戏引擎。仓库链接： [PillowBasics](https://github.com/ModulePillow/PillowBasics)

# Crucible V2
A built-from-bottom renderer powered by SharpDX (DirectX 12).

Focuses on showing and researching the modern graphics rendering pipeline.

Highlights:
- Realtime Mipmaps
- Realtime Shader Compilation
- Forward Renderering

Other features:
- Shader Reflections
- Heap Management
- Bitmap Font Rendering
